# PinMemory 

> Запазвай спомените си на картата — снимка, локация, дата и бележка на едно място.

---

## Идея

PinMemory е Android приложение, което позволява на потребителите да "закачат" спомени върху интерактивна карта. Всеки спомен съдържа заглавие, снимка, географски координати, локация, дата и бележка. Идеята е да се създаде визуален дневник, обвързан с реални места.

---

## Как работи

Потребителят се регистрира или влиза в профила си чрез Firebase Authentication. След вход вижда Google Maps с всичките си спомени като лилави пинове. При натискане на карта се избира локация и се отваря форма за нов спомен. Потребителят въвежда заглавие, избира снимка от галерията, задава дата чрез DatePicker и добавя бележка. Спомените се съхраняват локално в Room база данни и се синхронизират с Firestore. Приложението поддържа светла и тъмна тема, превключвани от бутон на картата.

## Архитектура

Проектът следва **MVVM (Model-View-ViewModel)** архитектурен шаблон с Repository pattern.

| Слой | Компоненти |
|------|-----------|
| **UI (View)** | Fragments, Adapters, XML Layouts |
| **ViewModel** | `MapViewModel`, `ListViewModel` |
| **Repository** | `MemoryRepository` |
| **Local DB** | Room – `MemoryDao`, `MemoryDatabase`, `MemoryEntity` |
| **Remote** | Firebase Auth, Firestore – `FirestoreDataSource` |

## Потребителски поток

```
Стартиране
    │
    ▼
Вход / Регистрация (Firebase Auth)
    │
    ▼
Map екран (Google Maps + пинове)
    │
    ├──► Натисни карта → Избери локация → Добави спомен (форма)
    │         └── Заглавие + Снимка + Дата + Бележка → Запази
    │
    ├──► Натисни пин → Детайли на спомена → Редактирай / Изтрий
    │
    ├──► Memories таб → Списък с всички спомени → Детайли
    │
    └──► Бутон тема → Превключи светла/тъмна тема
```

##  Стъпки за стартиране

### Изисквания
- Android Studio Ladybug или по-нова
- Android устройство / емулатор с API 24+
- Интернет връзка (Firebase)

### Стъпки

1. **Клонирай репото:**
   ```bash
   git clone https://github.com/StefaniStefanova/MobileApps2025-2301681050.git
   cd MobileApps2025-2301681050
   ```

2. **Отвори в Android Studio** – `File → Open → избери папката`

3. **Sync Gradle** – изчакай зависимостите да се изтеглят

4. **Стартирай** – натисни **Run ▶** или:
   ```bash
   ./gradlew assembleDebug
   ```

5. **Инсталирай APK** ръчно (виж секция APK)
